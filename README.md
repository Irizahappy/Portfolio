# Professional Portfolio

This is a static portfolio built with HTML, CSS and JavaScript.

## Before publishing

1. Open `script.js`.
2. Replace:
   - `YOUR_GITHUB_USERNAME` with your GitHub username.
   - `YOUR_LINKEDIN_USERNAME` with your LinkedIn profile username.
3. Replace `Your Name` in `index.html` with your preferred professional name.
4. Review the project descriptions and change anything that does not accurately describe your work.

## Publish with GitHub Pages

Create a public repository, upload these files, then enable GitHub Pages from:
Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

GitHub Pages can publish a static site directly from a repository.
